# Build pages visually. Keep Laravel in control.

FilaForge Studio is a visual page builder for Laravel and Filament 5. Editors compose responsive pages from reusable widgets and presets; Laravel stores validated, versioned JSON and renders published pages with Blade.

## Install

```sh
composer require filaforge-studio/filaforge-studio
php artisan filaforge:install
php artisan migrate
```

Register the plugin on each Filament panel that should manage pages:

```php
use FilaForge\Studio\Filament\FilaForgeStudioPlugin;
use Filament\Panel;

public function panel(Panel $panel): Panel
{
    return $panel->plugin(FilaForgeStudioPlugin::make());
}
```

## What you can build

- Responsive pages with containers, grids, columns, typography, buttons, media, tables, navigation, carousels, and interactive sections.
- Ready-to-edit sections such as hero, pricing, testimonials, FAQ, call to action, progress, wizard, and dropdown navigation.
- Persian, Arabic, English, and mixed-direction content, with page language and text direction independent from the admin UI.
- Media-backed pages with Laravel Filesystem uploads, folders, categories, image editing, and remote media URLs.
- Dynamic pages using explicitly registered and authorized data providers.
- SEO-ready Blade output and HTML helpers for fragments, full documents, and HTTP responses.

## How it works

The editor changes a local document tree and synchronizes validated updates with Livewire. The server stores versioned JSON, applies authorization and validation, and renders the published revision with trusted Blade widget views. Public pages do not load the editor runtime.
